# Stillframe 2

This is the new one. Do not use an older download.

The window title says **Stillframe 2**. It lists every window you hold. Click a name, then Bring back.

## Download

[Stillframe-2.zip](https://github.com/tarunmeenaofficial-droid/Stillframe/raw/main/Stillframe-2.zip)

1. Download Stillframe-2.zip.
2. Unzip it.
3. Right-click Stillframe.bat, open Properties, and tick Unblock if you see it.
4. Double-click it. If Windows warns you, choose More info, then Run anyway.
5. The window must say Stillframe 2. If it does not, you opened an old file.

Click a game, press Ctrl+Y. It keeps running. Click that name in Stillframe 2 to bring it back.
